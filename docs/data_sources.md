# Data Sources

## Dataset
- **Name:** Brazilian E-Commerce Public Dataset by Olist
- **Provider:** Olist (Brazilian marketplace)
- **Platform:** Kaggle
- **Link:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- **License:** CC BY-NC-SA 4.0
- **Access date:** 2026-10-22
- **Update frequency (per Kaggle):** Never (static snapshot)

## Scope
- Real commercial data, anonymized by the provider.
- Orders placed between 2016 and 2018.
- 9 CSV files, about 120 MB in total.

- This project is for portfolio and educational purposes only (non-commercial),
