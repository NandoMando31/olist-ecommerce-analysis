# Data

The raw data is **not stored in this repository** (license and file size).

## How to get it
1. Download the dataset from Kaggle:
   https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Unzip the file.
3. Place the 9 CSV files in `data/raw/`.

## Expected files
| File | Content |
|---|---|
| `olist_orders_dataset.csv` | Orders and delivery timestamps |
| `olist_order_items_dataset.csv` | Items in each order |
| `olist_order_payments_dataset.csv` | Payment details |
| `olist_order_reviews_dataset.csv` | Customer reviews |
| `olist_customers_dataset.csv` | Customer location |
| `olist_sellers_dataset.csv` | Seller location |
| `olist_products_dataset.csv` | Product attributes |
| `olist_geolocation_dataset.csv` | Zip code coordinates |
| `product_category_name_translation.csv` | Category names, Portuguese to English |

## Folder rules
- `data/raw/`: original files. Never edited. Ignored by git.
- `data/processed/`: cleaned tables generated by code. CSV files are ignored by git.
